# پشکنینی یاساکانی Firestore — ژینگەی ساختە

ئەم پشکنینانە بۆ پرۆژەی دارەجاتن، بەڵام هیچ کاتێک بە پرۆژەی ڕاستەقینەی قوتابخانە پەیوەست نابن.

## پاراستنی ژینگە

- Project ID ـی Emulator تەنها demo-daragat-sorani-rules ـە.
- Firebase CLI بە project ID ـی demo-daragat-sorani-rules دەست پێدەکات؛ هیچ .firebaserc یان project ID ـی ڕاستەقینەی Firebase پێویست نییە.
- تەنها Firestore Emulator دەکرێتەوە؛ هیچ پەیوەندییەک بە Firebase Authentication، Hosting یان بنکەدراوەی ڕاستەقینە ناکرێت.
- هەموو ناو، قوتابی، هەژمار و تۆمارەکان ساختە و تەنها لە Emulator ـدان.
- تاقیکردنەوەکان بە @firebase/rules-unit-testing هەژماری ساختەی admin/staff/viewer دروست دەکەن؛ وشەی نهێنی یان هەژماری ڕاستەقینە بەکارناهێنن.

## پێداویستییەکان

- Node.js 22
- Java 21 یان نوێتر (Firebase Emulator بە Java 17 لەم ژینگەیەدا ناکرێتەوە)
- پەیوەندی ئینتەرنێت بۆ یەکەم جار داگرتنی Firebase Emulator

## جێبەجێکردن لە کۆمپیوتەر

لە ڕەگی کۆگای GitHub:

    npm install
    npm run test:rules

فەرمانی دووەم بە خۆکاری Firestore Emulator لەسەر پۆرتی 8080 دەکاتەوە، تاقیکردنەوەکان جێبەجێ دەکات و Emulator دادەخات.

## ئەوەی تاقی دەکرێتەوە

1. کڕیارێکی نەچووەتەژوورەوە ناتوانێت داتای قوتابخانە بخوێنێتەوە.
2. دوو کڕیاری Admin دەتوانن هەمان ئەرشیفی داخراوی ساختە لە سێرڤەری هاوبەش بخوێننەوە.
3. Staff ناتوانێت ئەرشیفی ساڵ بخوێنێتەوە، دروست بکات، بگۆڕێت یان بیسڕێتەوە.
4. Staff دەتوانێت تۆماری ئامادەبوونی دروست بنووسێت.
5. Viewer و Admin ـی ناچالاک ناتوانن کردارە تایبەتەکان ئەنجام بدەن.
6. هەژمارێک ناتوانێت خۆی بۆ Admin بەرز بکاتەوە.
7. ئەرشیفی هەمان ID ناگۆڕدرێت و مانیفێستی نادروست ڕەت دەکرێتەوە.
8. دەسەڵاتی قوتابخانەیەک بۆ قوتابخانەیەکی تر ناگوازرێتەوە.

## سنووری ئەم پشکنینە

ئەمە پشکنینی یاساکانی Firestore و نووسین/خوێندنەوەی ساختە لە Emulator ـە؛ نە تاقیکردنەوەی چوونەژوورەوەی ڕاستەقینەی Email/Password، نە deployment ـی Rules، و نە تاقیکردنەوەی Hosting. بۆ تاقیکردنەوەی ڕاستەقینەی Firebase، پێویستە پرۆژەیەکی جیاوازی تاقیکردنەوە، هەژماری Admin و Staff ـی ساختە، و schoolId ـێکی ساختە ئامادە بکرێت. پرۆژەی ڕاستەقینەی قوتابخانە نابێت بۆ تاقیکردنەوە بەکاربهێنرێت.
