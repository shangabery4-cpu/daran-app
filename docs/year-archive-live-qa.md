# دارەجات — پشکنینی سەلامەتی ئەرشیفی سەحابی (هەنگاوی ٤)

## جیاوازی پشکنینەکان

- **Self-test (جێبەجێ کراو):** داتای ساختەی ناو بیرگە؛ تاقی SHA-256، ڕێگرتن لە دووبارەنووسین، conflict، پلانی هێنانەوە و Admin/Staff client guard. هیچ ناردنێک بۆ Firebase ناکات.
- **Firestore Rules ـی ڕاستەقینە (چاوەڕوان):** پێویستی بە Firebase Emulator یان پرۆژەی تاقیکردنەوەی جیاواز هەیە.
- **دوو ئامێری ڕاستەقینە (چاوەڕوان):** پێویستی بە هەژماری Admin و پرۆژەی Firebase ی تاقیکردنەوە هەیە؛ نە بە داتای قوتابیان.

## چۆنیەتی جێبەجێکردنی پشکنینی بێ مەترسی

١. لە پەڕەی پاشەکەوت، دوگمەی «🧪 تاقیکردنەوەی سەلامەتی» بکە. دەبێت ٧ لە ٧ پشکنین سەرکەون و ژمارەی نووسینی Firebase سفر بێت.

٢. بۆ پشکنینی ڕاستەقینەی سێرڤەر، لە **Firebase project ـێکی جیاوازی تاقیکردنەوە** و وەشانی جیاوازی سایتەکە کار بکە؛ `online/config.js` ی ئەو وەشانی تاقیکردنەوەیە بە پرۆژەی تاقیکردنەوە پەیوەست بکە. `schoolId` بە ناسنامەی قوتابخانەی ساختە جیا بکەرەوە.

٣. `online/firestore.rules` تەنها دوای بەراوردکردن لەگەڵ Rules ـی هەنووکەیی پرۆژەی تاقیکردنەوە بڵاو بکەرەوە. `allow read, write: if true` هەرگیز بەکارمەهێنە.

٤. لە Firebase Authentication، هەژماری تاقیکردنەوەی Admin و Staff دروست بکە. بۆ هەژماری Admin، لە `schools/{schoolId}/members/{uid}` تۆماری `{active: true, role: 'admin'}` بە ڕێگای Console ی بەڕێوەبەر دابنێ؛ Staff ـەکە `{active: true, role: 'staff'}` بێت. هەژماری Staff خۆی ناتوانێت دەسەڵاتی Admin بەخۆی بدات.

٥. لە ئامێری A، ئەرشیفێکی **ساختە** دابنێ و بە Admin بینێرە. پشکنە تەنها `yearArchives/{archiveId}` و پارچەکانی نووسراون. ساڵی کارا لەناو Firebase yearArchives ـدا نابێت دەرکەوێت.

٦. دووبارە هەمان ئەرشیف بنێرە. دەبێت «پێشتر پارێزراوە» نیشان بدات و **٠ نووسینی نوێ** دروست بکات.

٧. لە ئامێری B بە هەمان Admin بچۆ ژوورەوە؛ دوگمەی «داگرتنی JSON لە Firebase» بکە و فایلەکە دواتر وەک ئەرشیفی ناوخۆیی بهێنەوە. هەروەها «زیادکردنی ئەم ساڵە بۆ ئەرشیفی ئامێر» تاقی بکەوە. هەردوو ڕێگاکە دەبێت ناوەڕۆکی هەمان ساڵی ساختە بدەنەوە، بەبێ گۆڕینی ساڵی کارا.

٨. بە Staff هەوڵ بدە `yearArchives` بخوێنیتەوە و بنووسیت. هەردوو دەبێت لە سێرڤەر ڕەت بکرێنەوە (`permission-denied`). ئەمە بە تەنها بە disabled button ناپشکنرێت.

٩. هەوڵی هێنانەوەی ئەرشیفی هەمان ID بە ناوەڕۆکی جیاواز بکە؛ دەبێت ڕەت بکرێتەوە و هیچ ئەرشیفێکی هەبوو نەگۆڕدرێت.

١٠. بە سنووری قەبارە، فایلێکی ساختەی زیاتر لە ٦ MB تاقی بکەوە؛ ناردن دەبێت **پێش** نووسینی Firestore ڕەت بکرێت. فایلە گەورەکان تەنها بە JSONی ناوخۆیی هەڵبگیرێن.

## دۆخی ئەم قۆناغە

**کۆدی تاقیکردنەوەی ساختە جێبەجێ کراوە.** پشکنینی ڕاستەقینەی Firebase، دەسەڵاتی سێرڤەر و دوو ئامێر هێشتا تەواو نییە؛ پێویستی بە پرۆژەی تاقیکردنەوە و Admin ـی چالاک هەیە. داتای قوتابیان بۆ پشکنین بەکارمەهێنە.
