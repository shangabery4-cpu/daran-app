# دارەجات — نەخشەی تەواوکردنی سیستەمی قوتابخانە

**ئامانج:** وەشانی کوردیی سۆرانی (RTL) بە هەمان توانایە سەرەکییەکانی «منظومة الإدارة المدرسية الذكية» لەسەر هەموو قۆناغە پەروەردەییەکان؛ داتای هەنووکەیی و تواناکانی بەرنامەی ئەسڵی بپارێزرێن.

**دۆخی ئەم بەڵگەنامەیە:** پشکنینی کۆد + پلان؛ **نەک بڕوانامەی ئەوەی هەموو کاراییەکان تاقی کراونەتەوە.**
**بنچینە:** `parts/part-000.txt` تا `parts/part-024.txt`، و ماژوولەکانی `online/`. ئەپەکە لە `index.html` کۆ دەکرێتەوە.

## پشکنینی بنەڕەتی کۆد

| بوار | بەڵگەی کۆدی هەنووکە | هەنگاوی پێویست |
|---|---|---|
| نمرە، ئەنجام، بڕوانامە | `renderGradesView`, `exportResultsPDF`, `issueGradebookSectionResults` | تاقیکردنەوەی ژمێریاری هەموو قۆناغەکان، بڕیاری نمرە، ئەعفاء و بارکۆد |
| تاقیکردنەوە و پرسیار | `generateSeatingPlan`, `generateExamList`, `generateMonthlyExamSchedule`, `generateQuestionPaper`, `saveQuestionPaper` | دروستیی چاپی A4، قەبارەی شاشە، پرسیاری کوردی، هەموو جۆرە تاقیکردنەوەکان |
| مامۆستا و دەسەڵات | `authSyncStaffAccounts`, `teacherSetScore`, `teacherOpenExam`, `importResults` | دەسەڵاتی هەر بابەت/پۆل لە سێرڤەر، هاوکاتکاریی دوو ئامێر و چارەسەری ناکۆکی |
| قوتابی و گواستنەوە | `openStudentTransfer`, `saveStudentTransfer`, `saveBulkStudentTransfer` | ناسنامەی جێگیر، پاراستنی نمرەی مێژوویی، هەڵە و دووبارەبوونەوە |
| تۆمارە فەرمییەکان | `view-records`, تۆماری نمرە و ئاگادارکردنەوەی نەهاتن | لیستی هەموو تۆمارە داواکراوەکان + چاپ/هەناردەی هەر یەک |
| ئەرشیف و ساڵی نوێ | `storeArchive`, `applyNewYear`, `syncYear` لە `part-017` | تاقیکردنەوەی ڕێگرتن لە داتای لەدەستچوو، گەڕاندنەوەی وەشانی پێشوو |
| ستاف و بەڵگەکان | `remainingService`, `openStaffDocuments`, `exportStaffExcel`, `importStaffExcel` | پشکنینی ساڵانی خزمەت، بەڵگەی PDF/وێنە، چاپ و دەسەڵاتی بینین |
| چاپ و Excel/Word/PDF | `exportExamPDF`, `exportResultsPDF`, و `XLSX` | تاقی چاپی کوردی، قەبارەکان، import/export بەبێ گۆڕانی داتا؛ Word بە جیا |
| نامە و پەیوەندی | `teacherSend`, پەیوەندیی WhatsApp و بەشی نامە | پشتڕاستکردنەوەی نامەی ئۆنلاین و هاوبەشکردنی فایل بەڕێگەی مۆڵەت |
| موڵک، هەتیوان، ژمێریاری | مێنیو و ڕووکاری بەشەکان لە ئەپی بنەڕەتی | جێبەجێکردنی سناریۆکانی تۆمار، گەڕان، هەناردە، ڕاپۆرت و پاککردنەوە |
| قۆناغەکان | سەرەتایی، ناوەندی، ئامادەیی، دواناوەندی و بنەڕەتی لە ڕووکار؛ ئاماژەی professional لە کۆد | پشکنینی پیشەیی و ئامادەیی ئیسلامی و یاساکانی نمرەی هەر قۆناغ |
| Firebase و هەژمار | `online/legacy-sync.js`, `online/social-auth.js`, `online/social-link.js` | یەکخستنی هەژمار و داتا؛ login ی سۆشیال تەنها دوای چالاککردنی provider و account linking |

**گرنگ:** «function هەیە» بە مانای «ئەو کارە لە هەموو دۆخەکاندا سەرکەوتووە» نییە؛ هەر ڕیزێک پێویستی بە تاقیکردنەوەی end-to-end هەیە.

## قۆناغەکانی جێبەجێکردن

### جێبەجێکراوەکانی پاراستنی داتا
- ٢٠٢٦-١١-٠٨: ڕێگرتن لە نووسینەوەی وەشانی کۆنی Firebase لە کاتی پاشەکەوتی دوو ئامێر، و داگرتنی یەدەکی ناوخۆیی بۆ بەشە دیاریکراوەکان.
- ٢٠٢٦-١١-٠٩: هەناردە و هێنانەوەی جیاوازی ساڵە ئەرشیفکراوەکان لە IndexedDB، بە تۆمارکردنی هەڵەی هاوناسنامە و بێ گۆڕینی نمرەکانی ئێستا. **ئەمە هێشتا cloud sync نییە.**
- ٢٠٢٦-١١-٠٩ — هەنگاوی سێیەم: دەستی ناردن/هێنانەوەی **تەنها یەک ساڵی داخراو** لە Firebase؛ ئەرشیفی سەحابی ناگۆڕدرێت، گەڕاندنەوە زیادکردنە بەبێ نووسینەوەی ساڵی کارا. سنووری ٦ MB و ٧٣ نووسینی هەر ساڵ بۆ کەمکردنەوەی quota؛ پێویستی بە بڵاوکردنەوەی `online/firestore.rules` هەیە.
- ٢٠٢٦-١١-٠٩ — هەنگاوی چوارەم: پشکنینی ٧ قۆناغەیی بە داتای ساختە (لە بیرگە، بەبێ خوێندنەوە/نووسینی داتای ڕاستەقینە)، سەلماندنی جیاوازی Admin/Staff لە گەیتەکەی ڕووکار، و داگرتنی JSON ـی ئەرشیفی سەحابی دوای پشکنینی SHA-256. ڕێنماییی پشکنینی سێرڤەر: `docs/year-archive-live-qa.md`.
- هیچ یەدەکێک یان هێنانەوەیەک بە هەژماری ڕاستەقینەی Firebase تاقی نەکراوەتەوە؛ پێویستی بە تاقیکردنەوەی ئامێری دووەم هەیە.

### P0 — پێداچوونەوە و پاراستنی داتا
- داتای نموونەیی دروست بکە بۆ هەر قۆناغ؛ لەداتای بەکارهێنەری ڕاستەقینە تاقی مەکەوە.
- توانای export/import و backup/restore پشکنە؛ پێش گۆڕانکارییە گەورەکان کۆپیی یەدەک هەبێت.
- جیاوازی نێوان داتای localStorage/IndexedDB و Firebase بە ڕوونی نیشان بدە.
- تۆماری «کار دەکات / کێشە هەیە / پشتڕاست نەکراوە» بۆ هەر بەشێک تۆمار بکە.

### P1 — یەکخستنی بنەمای پارێزراوی ئۆنلاین
- هەژماری Admin/Staff و دەسەڵاتەکان لە Firestore Rules، نە تەنها لە UI.
- Google/Apple/Facebook/Microsoft linking بە هەمان Firebase UID؛ هەر provider دوای چالاککردنی Firebase تاقی بکەوە.
- هاوکاتکردنی داتا لە چەند ئامێردا؛ ڕێگری لە last-write-wins بۆ گۆڕانکارییە هەستیارەکان.
- offline queue بە idempotency و متمانە بە وەڵامی سێرڤەر پێش نیشاندانی «پاشەکەوت کرا».
- کۆنترۆڵی خوێندنەوە/نووسین بۆ نەچوونە دەرەوەی quota ی پلانی بەخۆڕایی؛ بەڵێنی «بێ سنوور» مەدە.

### P2 — قوتابی، نمرە، ساڵ و ئەرشیف
- تۆمارکردنی قوتابی، هاوردەی Excel، گواستنەوەی تاک/کۆمەڵ.
- ئەنجامی خۆکار و فەرمانی نمرە، ئیعفاء، پۆلەکانی جیاواز.
- «کۆتایی ساڵ» بە preview و confirm و snapshot، نە بە سڕینەوەی ڕاستەوخۆ.
- گەڕانەوە بۆ ساڵی پێشوو بە شێوەی read-only و چاپکردنی ڕاپۆرتی مێژوویی.

### P3 — تاقیکردنەوە، ستاف، تۆمار و پەیوەندی
- نەخشەی دانیشتن و کارت و خشتەکان بۆ هەموو قۆناغەکان.
- پرسیار دروستکردن بە شێوەی دوو ستوونی/کوردی، پێشبینین و چاپ.
- ستاف: خزمەت، بەڵگەکان، تۆماری فەرمی و هەناردەی پاک.
- پەیوەندی مامۆستا/بەڕێوەبەر/دایک‌وباوک بە دەسەڵاتی دیاریکراو.

### P4 — کاریگەری و کوالێتی بۆ هەموو کۆمپیوتەر و مۆبایلێک
- 100٪ Sorani/RTL و فونتی کوردی لە تابی هەموو بەشەکان و چاپ.
- پشکنینی 360px مۆبایل، تابلێت، 1080p و 4K.
- تاقی export PDF/Excel/Word و چاپی A4 landscape/portrait.
- ڕووکاری خێرا، جێگیر و بەشە سەربەخۆکان بۆ گۆڕانکاریی داهاتوو.

## پێوەری قبوڵکردنی هەر تایبەتمەندییەک

- [ ] بە هەژماری Admin کار دەکات؛ Staff تەنها دەسەڵاتی خۆی هەیە.
- [ ] داتای داخڵکراو دەمێنێتەوە دوای refresh، logout/login و ئامێری دووەم (ئەگەر cloud بوو).
- [ ] ئەو کارە کە نووسینەوەی داتا پێویستە، تەنها دوای گەڕانەوەی وەڵامی سەرکەوتووی سێرڤەر کۆتایی پێ دەهێنرێت.
- [ ] دووبارەکردنەوەی هەمان کردار داتای دووبارە یان لەدەستچوو دروست ناکات.
- [ ] مۆبایل و کۆمپیوتەر و چاپی کوردی بێ تێکچوونن.
- [ ] backup/restore ی ئەو بەشە تاقی کراوەتەوە.
- [ ] Firestore Rules تاقیکراونەتەوە: نا-چووەژوورەوە، Staff، Admin و بەکارهێنەری قوتابخانەی دیکە.

## ڕێکاری کارکردن لە GitHub

١. هەر گۆڕانکارییەک لە branch ـێکی جیا بکە؛ ئەپە بنەڕەتییەکە مەگۆڕە تا تاقیکردنەوە تەواو نەبێت.
٢. کۆد و تاقیکردنەوەکان پێکەوە بخەرە PR.
٣. لە وەشانی نموونەیی و UI ی کۆمپیوتەر/مۆبایل پشکنین بکە.
٤. دوای سەرکەوتن merge/deploy بکە؛ rollback لە GitHub هەبێت.
٥. هەرگیز Firebase Rules بە `allow read, write: if true` فراوان مەکە و هەژمارە نەناسراوەکان بە کار مەهێنە.

**بڕیاری پرۆژە:** سەرەتا ئەو توانایانە تەواو بکە کە لە کۆدی ئەسڵی هەن بەڵام تاقی نەکراونەتەوە؛ دواتر بۆ کەم‌وکورتییەکان ماژوولی نوێ دروست بکە. یەکخستنی Firebase قۆناغێکی گرنگ و پێویستە، بەڵام پێویستە لە تاقیکردنەوەی ڕوون و بکاپی دڵنیا دەست پێ بکات.
