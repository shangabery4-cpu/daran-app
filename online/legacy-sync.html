☁️ پاشەکەوتی سەحابیی دارەجات

پەیوەستکردنی تۆمارەکانی وەشانی ئەسڵی دارەجات بە Firebase — بە هەمان ڕووکار و پەڕەکان

ئەم بەشە تەنها ئەو داتایانە دەپارێزێت کە لە لیستی خوارەوەدا دیاریکراون. ئەرشیفی ساڵانی پێشوو لە IndexedDB، و داتای بەشی ئامادەبوونی ئۆنلاین بە جیاوازن و لێرەدا ناگوێزرێنەوە. ئەرشیفەکان دەتوانیت وەک JSON داگرێیت یان بە فەرمانی بەڕێوەبەر هەر ساڵێک بە جیا لە Firebase بپارێزیت.
بۆ پاراستنی هەژمارەکان، وشە نهێنی، زانیارییەکانی چالاککردن و مۆڵەتەکان هەرگیز بۆ ئەم پاشەکەوتە ناگوێزرێنەوە. ئەمە لەگەڵ تۆماری ئامادەبوونی نوێی ئۆنلاین، دوو سەرچاوەی جیاوازن؛ تۆمارەکان خۆکارانە یەکناخرێن.
سیستەمی هاوکاتکردن ئامادە دەکرێت…

🔐 ناسنامەی پارێزراوی Firebase

چوونەژوورەوە پێویستە

تەنها هەژماری بەڕێوەبەری چالاک دەتوانێت پاشەکەوت و گەڕاندنەوە بکات.

📚 بەشە دیاریکراوەکانی پاشەکەوت

بەشەکان لە هەمان وێبگەڕ کۆ دەکرێنەوە؛ هیچیان لە سێرڤەر نانووسرێت تا تۆ داوا نەکەیت.

٠ بەش لە ئامێری ئێستا • — لە Firebase

ئەم فایلە تەنها بۆ بەشە دیاریکراوەکانە و وشەی نهێنی و هەژمارەکان تێدا نییە.

🗄️ ئەرشیفی ساڵەکانی پێشوو — یەدەکی سەربەخۆ

هەموو ساڵە کۆتایی‌پێهاتووەکان لە IndexedDB بخەرە فایلێکی JSON، یان لە ئامێرێکی دیکە زیاد بکەرەوە. هێنانەوە تەنها ئەرشیفە نوێکان زیاد دەکات؛ نمرە و قوتابییەکانی ساڵی ئێستا و ئەرشیفە پێشووترەکان ناگۆڕێت.

ئەم هەڵبژاردنە بە Firebase پەیوەست نییە. فایلەکە زانیارییە تایبەتییەکانی ساڵەکانی پێشوو لەخۆ دەگرێت؛ لە شوێنێکی پارێزراو هەڵیبگرە.

☁️ ئەرشیفی سەحابیی ساڵانی داخراو — بە دەستی بەڕێوەبەر

هەر ساڵێکی ئەرشیفکراو بە جیا بۆ Firebase بنێرە یان بۆ ئەم ئامێرە زیاد بکەرەوە. هیچ شتێک خۆکارانە نانێردرێت؛ ئەو ئەرشیفەی لە Firebase پارێزرا نابێتەوە بە نووسینێکی جیاواز.

بۆ ناردن یان هێنانەوە پێویستە هەژماری Firebase ـی بەڕێوەبەر هەبێت.

سنووری هەر ساڵێکی سەحابی: ٦ MB (پێش کەمکردنەوەی قەبارە)، زۆرترین ٧٣ نووسین بۆ هەر ناردنێک. ئەرشیفی گەورەتر لە JSON بپارێزە. ئەم تایبەتمەندییە بە Firestore Rules ـی yearArchives پێویستە؛ ئەرشیفەکان زانیاری تایبەتی قوتابییان لەخۆ دەگرن.

🔄 گواستنەوەی سەلامەت

بۆ هاوبەشکردنی داتاکان لەگەڵ ئامێرێکی دیکە، سەرەتا «ناردن بۆ Firebase» لەم ئامێرە بکە، دواتر لە ئامێری دووەم «هێنانەوە لە Firebase» هەڵبژێرە.

ناردن، وەشانی پێشووی هەر بەشێکی سەحابی بە وەشانێکی نوێ دەگۆڕێت. هێنانەوە، تۆمارە ناوخۆییە هاوشێوەکان دەگۆڕێت و پەڕەکە دووبارە بار دەکات. بۆ ئەوەی لە ئامێری دیکە کار بکات Firestore Rules ـی نوێ لە Firebase Console بڵاو کرابێتەوە.
