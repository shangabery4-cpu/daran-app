# دارەجات — بنەمای نوێی ئۆنلاین

ئەم فۆڵدەرە یەکەم هەنگاوە بۆ سیستەمێکی ڕاستەقینەی ئۆنلاین بە **کوردیی سۆرانی**. بە ئەنقەست جیا کراوەتەوە لە کۆدی کۆنی `parts/`؛ هیچ سیستەمی مۆڵەت/تاقیکردنەوەی کۆن، وشەی نهێنی ناوخۆیی یان Firebase ـی خاوەن پێشوو بەکارناهێنێت.

## لەم وەشانەدا چی ئامادەیە؟

- چوونەژوورەوە بە Firebase Authentication (ئیمەیڵ/وشەی نهێنی)، بەبێ تۆمارکردنی وشەی نهێنی لە کۆدی خۆمان.
- مۆڵەتەکان لە Firestore ـدا: `admin` و `staff`. هەژمار ناتوانێت ڕۆڵی خۆی بگۆڕێت.
- پاشەکەوتی سەحابیی لیستی قوتابی و دۆخی ڕۆژانە (ئامادە/نائامادە/مۆڵەت‌پێدراو).
- بەڕێوەبەر دەتوانێت ناو و پۆلی قوتابی بگۆڕێت؛ ناسنامەی قوتابی ناگۆڕێت و تۆماری ئامادەبوونی پێشوو دەپارێزرێت.
- ڕاپۆرتی ڕۆژانە بە CSV ـی کوردی و چاپکردن، بەپێی فلتەری پۆل/گەڕان؛ فۆرمولەی مەترسیدار لە خانەکانی CSV قەدەغە دەکرێت.
- مێژووی ڕۆژەکان: هەڵبژاردنی بەروار، دوگمەکانی ڕۆژی پێشوو/داهاتوو و گەڕانەوە بۆ ئەمڕۆ؛ تۆمارە کۆنەکان تەنها بە هەڵبژاردنی ڕۆژ دەخوێنرێنەوە.
- ڕاپۆرتی مانگانە: ژمارەی ئەو ڕۆژانەی تۆمارکراون بۆ هەر قوتابی (ئامادە/نائامادە/مۆڵەت‌پێدراو)، لەگەڵ داگرتنی CSV. دۆخی دیاری‌نەکراو لە هیچ ستوونێکدا ناحەژمێردرێت.
- بەڕێوەبردنی پۆلەکان: هەڵبژاردنی پۆل بەپێی قوتابی، و گۆڕینی کۆمەڵەیی ناوی پۆل تا ٢٠ قوتابی لە جارێکدا بە پشتڕاستکردنەوەی بەڕێوەبەر؛ هەر قوتابی هەمان ناسنامەی خۆی دەپارێزێت.
- بەڕێوەبردنی ڕۆڵ: بەڕێوەبەر دەتوانێت لیستی ئەندامان و دۆخی چالاکییان بخوێنێتەوە؛ دروستکردن/گۆڕینی ڕۆڵ تەنها لە Firebase Console یان سێرڤەری پارێزراو ئەنجام دەدرێت. مامۆستا دەسەڵاتی زیادکردن و دەستکاریکردنی قوتابی نییە.
- خوێندنەوەی قوتابی تەنها جارێک بۆ هەر دانیشتنێک، بە هەڵگرتنی ڕۆژە خوێندراوەکان لە بیرگەی کاتیی پەڕە؛ «نوێکردنەوە» بە ئاشکرا زانیاریی ڕۆژ و قوتابی دووبارە لە Firebase دەخوێنێتەوە.
- شاشەی تەنها پیشاندان لە `online/display.html`: تەنها بۆ هەژماری چالاکی `admin`/ `staff`، بەبێ هیچ نووسینێک بۆ Firestore. سێ پۆل لە هەر پەڕەیەک، گۆڕینی خۆکاری هەر ١٢ چرکە، سێ زمان، شاشەی پڕ و سکرۆڵی ناوخۆیی.
- QR ـی `online/qr-display.svg` تەنها ناونیشانی شاشەکە لەخۆدەگرێت. کەسێک کە QR ـەکە بکاتەوە بەبێ چوونەژوورەوە ناوی قوتابی نابینێت. ئەمە لە هەمان کاتدا **شاشەی گشتیی بێ‌پاسوۆرد نییە**.
- شاشەکە دۆخی ئامادەبوون لە سێرڤەر هەر ١٥ خولەک جارێک نوێ دەکاتەوە، بەبێ `onSnapshot`؛ لیستی قوتابی تەنها لە سەرەتادا یان دوگمەی نوێکردنەوە دەخوێنرێتەوە. هەر شاشەیەک بەجیا خوێندنەوەی Firebase بەکاردەهێنێت.
- ڕاپۆرتی ٧ ڕۆژەی تاکە قوتابی بۆ دایک‌وباوک، بە پیشاندانی ناو پەڕە، CSV و چاپکردن. ئەم ڕاپۆرتە بە تەنها لەلایەن بەڕێوەبەر/مامۆستای مۆڵەتپێدراو دروست دەکرێت؛ خۆکارانە لەگەڵ دایک‌وباوک هاوبەش ناکرێت.
- نیشاندانی بنەڕەتی پشووی هەینی و شەممە. ئەگەر دۆکیومێنتی `schools/{schoolId}` هەبێت، فیلدەکانی `termStart`, `termEnd`, `workingSaturdays`, `holidays` تەنها دەخوێنرێنەوە؛ لەم وەشانەدا ڕێکخستنەکان لە خودی پەڕەدا نانووسرێن.

- کەمکردنەوەی نووسینی دووبارە: دۆخی هەمان قوتابی دووبارە نانێردرێت، تەنها دوای پشتڕاستکردنەوەی سێرڤەر نیشانی سەرکەوتن دەدرێت.
- ڕووکاری RTL و ژمارەی کوردی. هەموو دەقەکانی ئەم فۆڵدەرە بۆ بەکارهێنەر بە سۆرانی نووسراون.
- ڕێکخستنی گشتیی Web App ـی Firebase لە `online/config.js` دانراوە، بەڵام چوونەژوورەوە، ئەندامێتی و یاساکانی بنکەدراوە هێشتا دەبێت تاقی بکرێنەوە. هیچ داتای ڕاستەقینەی قوتابی تێدا مەنووسە تا ئەو تاقیکردنەوانە تەواو نەبن.

**گرنگ:** ئەمە وەشانی تەواوی Daragat نییە. بەشەکانی نمرە/تاقیکردنەوە، ڕاپۆرتی تایبەتی دایک‌وباوک، هەژماری دایک‌وباوک، مۆڵەتی پیشاندانی گشتی، کاری ئۆفلاین، پاشەکەوتی وێنەکان و هێنانی داتای کۆن هێشتا زیاد نەکراون. پێش بەکارهێنانی ڕاستەقینە، یاساکان لە Firebase Emulator تاقی بکرێنەوە و پشکنینی ئەمنی بکرێت.

## چۆن چالاکی بکەیت؟

1. پڕۆژەیەکی نوێ لە [Firebase Console](https://console.firebase.google.com/) دروست بکە.
2. `Authentication → Sign-in method → Email/Password` چالاک بکە. هەژماری بەڕێوەبەر لە `Authentication → Users` دروست بکە.
3. `Firestore Database` دروست بکە بە **production mode**. یاساکانی `online/firestore.rules` بخوێنەوە، لە Emulator تاقیان بکەرەوە و پاشان لە `Firestore → Rules` بڵاویان بکەرەوە. بە هەرگیز `allow read, write: if true` بەکارمەهێنە.
4. لە Firestore ـدا لە ڕێگەی Console ـەوە ئەم پەڕەیە دروست بکە: `schools/daragat-sorani/members/USER_UID`، لەگەڵ خانەکانی `role: "admin"` و `active: true`. `USER_UID` لە Firebase Authentication وەرگرە؛ پێش تۆمارکردنی داتای ڕاستەقینە، `schoolId` دەتوانرێت بگۆڕدرێت.
5. ڕێکخستنە گشتییەکانی Web App ـی پڕۆژەی `daragat-sorani` لە `online/config.js` دانراون. `service-account`، `private key`، پاسوۆرد، OTP یان توکنی بەڕێوەبەر لە GitHub مەخەرەوە.
6. لە Firebase Authentication → Settings → Authorized domains، دۆمەینی `shangabery4-cpu.github.io` زیاد بکە، ئەگەر پێویست بوو.
7. دوای پشکنین و merge کردنی PR بۆ `main`، پەڕەی `https://shangabery4-cpu.github.io/daran-app/online/` بکەرەوە (بە مەرجێک GitHub Pages چالاک بێت).

## پاراستن و بەکارهێنان

- هەژماری یەکەم و مۆڵەتەکان تەنها لە Firebase Console/سێرڤەری متمانەپێکراو دروست بکرێن، نەک بە client ـی گشتی.
- `firebaseConfig` (public web settings) پەنهانە نییە، بەڵام ئەمە **جێگرەوەی Security Rules نییە**.
- Firestore ـی Spark سنووری خوێندنەوە/نووسین و بڕی هەڵگرتنی هەیە. ئەم کۆدە دڵنیایی بەکارهێنانی بێ‌سنوور یان هەمیشە بێ‌پارە نادات.
- بەڕێوەبردنی هەژمارەکان، هەڵگرتنی پاشەکەوت و هێنانەوەی داتا و پشکنینی ڕۆڵەکان پێش بەکارهێنانی فەرمی پێویستن.
- کۆدی بنەڕەتی Daragat لە [سەرچاوەیەکی دیکە](https://github.com/hussainnahi1989-ctrl/Daragat) هاتووە. مۆڵەتی دەستکاریی سیستەمی مۆڵەت/پارەدان لەو سەرچاوەیە پێویستە بەجیا ڕوون بکرێتەوە؛ ئەم بنەمایە بەبێ بەکارهێنانی ئەو بەشە لە نوێوە نووسراوە.

## دۆخی وەرگێڕان

ڕووکاری نوێی `online/` بە سۆرانییە. لە وەشانی کۆنی `index.html`، هێشتا دەقی عەرەبی و دۆخە نەوەرگێڕدراوەکان هەن؛ نابێت پێی بڵێین ١٠٠٪ کوردی. بۆ وەرگێڕانی تەواو پێویستە هەموو مۆداڵ، ڕاپۆرت، چاپکردن، ئاگاداری و هەڵەکانی وەشانی کۆن بە تاقیکردنەوەی ڕووکاری بکرێن.

## تاقیکردنەوەی قۆناغی دووەم

1. بە هەژماری بەڕێوەبەر بچۆ ژوورەوە؛ ڕۆژی پێشوو و داهاتوو تاقی بکەرەوە و لەگەڵ بەرواری دەستی بەراورد بکە.
2. بۆ ڕاپۆرتی مانگانە، سەرەتا تەنها مانگی تاقیکردنەوە هەڵبژێرە. پێش خوێندنەوەی Firebase، ئاگادارکردنەوەی ژمارەی داواکاری دەردەکەوێت. ٣١ ڕۆژ × ٥٠ قوتابی دەتوانێت نزیکەی ١٥٥٠ خوێندنەوەی دۆکیومێنت بەکارهێنێت، هەرچەندە تەنها دۆکیومێنتە هەبووەکان دەخوێنرێنەوە؛ داواکاری بەتاڵیش تێچووی کەمترین خوێندنەوەی هەیە.
3. بۆ پۆلێکی تاقیکردنەوە کە تا ٢٠ قوتابی هەیە، هەڵبژاردن و گۆڕینی ناوی پۆل تاقی بکەرەوە؛ ئەم کردارە بە تەنها یەک `writeBatch` ئەنجام دەدرێت و هەر قوتابی یەک نووسینە.
4. بە هەژماری `staff` تاقی بکەرەوە: پۆل و هەژمارەکان نابێت دەستکاریکراو بن؛ تەنها تۆمارکردنی ئامادەبوون مۆڵەتی هەیە. هەژماری `staff` لە Console دروست بکە؛ هیچ پاسوۆردێک لە GitHub مەنووسە.
5. Firestore Rules لەم PR ـەدا نەگۆڕاون. سەرکەوتنی دەستکاریکردنی UI جێگەی پشکنینی ئەمنی و تاقیکردنەوەی Emulator ناگرێتەوە.

**تێبینی ڕاپۆرت:** ناوی پۆلی قوتابی لە ڕاپۆرتی مانگانە، پۆلی **ئێستای** قوتابییە. ئەگەر قوتابی گواسترابێتەوە، دۆخەکانی مانگە پێشووتر لە ژێر ناسنامەی هەمان قوتابیدا دەمێننەوە، بەڵام مێژووی پۆلی پێشوو بە شێوەی جیاواز لە داتابەیسەکەدا تۆمار نەکراوە.

## قۆناغی سێیەم — ڕێنمایی بەکارهێنانی پارێزراو

### شاشەی قوتابخانە و QR

- لینکی `https://shangabery4-cpu.github.io/daran-app/online/display.html` لە QR ـەکەدایە؛ QR هیچ ناو و دۆخی قوتابی تێدا نییە.
- بە هەژماری `admin` یان `staff` بچۆ ژوورەوە؛ ئەم پەڕەیە هیچ دوگمەی گۆڕینی ئامادەبوون یان گەڕانەوە بۆ داشبۆردی قوتابخانەی تێدا نییە.
- هەژماری `staff` لە بنکەدراوەدا هێشتا مۆڵەتی نووسینی ئامادەبوونی هەیە؛ بۆ ئەوەی هەژماری تایبەتی «تەنها خوێندنەوە» دروست بکرێت، پێویستە ڕۆڵێکی نوێ و Firestore Rules ـی تاقیکراو زیاد بکرێن. تا ئەو کاتە هیچ پاسوۆردێک لە شوێنی گشتی مەهێڵە.
- گۆڕینی سێ پۆل هەر ١٢ چرکە هیچ خوێندنەوەیەک بۆ Firebase نادات. نوێکردنەوەی دۆخ هەر ١٥ خولەک جارێکە؛ ٤٠–٥٠ قوتابی دەتوانێت نزیکەی ٤٠٠٠–٥٠٠٠ خوێندنەوە بۆ هەر شاشەیەک لە ٢٤ کاتژمێردا بەکارهێنێت. ئەمە سنووری گشتی/سێرڤەری و دڵنیایی بەخۆڕایی نییە.

### ڕێکخستنی ساڵی خوێندن

لە Firebase Console → Firestore Database → Data، دۆکیومێنتی `schools/daragat-sorani` بکەرەوە (ئەگەر نییە بە Console دروستی بکە) و ئەم فیلدانە بە پێویست دابنێ:

- `termStart` — String، وەک `2026-09-01`
- `termEnd` — String، وەک `2027-06-30`
- `workingSaturdays` — Array of strings، بۆ شەممەکانی دەوامی تایبەت
- `holidays` — Array of strings، بۆ پشووە تایبەتەکان

**گرنگ:** هەموو کات و بەروارەکانی سەرەوە نموونەن، بەرواری ڕاستەقینەی قوتابخانەکەت لەخۆت وەرگرە. نیشانەی پشوو تەنها زانیارییە و تۆمارکردنی ڕۆژانی پێشووی پشوو قەدەغە ناکات.

### زیادکردنی مامۆستا

1. لە Firebase Authentication → Users هەژماری مامۆستاکە دروست بکە و UID ـی وەرگرە.
2. لە Firestore Console دۆکیومێنتی `schools/daragat-sorani/members/UID` دروست بکە.
3. فیلدەکانی `role: "staff"` (string) و `active: true` (boolean) تێدا دابنێ. هیچ پاسوۆرد یان تۆکنی تایبەت لە GitHub مەنووسە.

### پشکنینی ئەمنی

- `firestore.rules` و `config.js` لە قۆناغی سێیەمدا نەگۆڕاون.
- هەژمارە نەناسراوەکان ناتوانن داتای قوتابی بە `display.html` بخوێننەوە. تەنها UI ـی «تەنها پیشاندان» بەمانای مۆڵەتی خوێندنەوەی تایبەت لە Firestore نییە.
- ڕاپۆرتی ٧ ڕۆژە تەنها بە داواکاری کاربەری چووەژوورەوە دروست دەکرێت؛ پێش هاوبەشکردن، ناسنامەی دایک/باوکی وەرگر بپشکنە.
- پێش داتای ڕاستەقینە، تاقیکردنەوەی ئەمنی Firestore Emulator و سیاسەتی ڕەزامەندی و پاراستنی داتای قوتابی پێویستە.
