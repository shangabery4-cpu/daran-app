function barcodeNorm(s){return String(s||'').replace(/[إأآا]/g,'ا').replace(/ى/g,'ي').replace(/ة/g,'ه').replace(/\s+/g,' ').trim();}
function barcodeParsePayload(text){  const t=barcodeFixText(String(text||'').trim());
  const out={raw:t,name:'',grade:'',section:'',seq:'',id:'',nationalId:'',result:'',subjects:[]};
  const m=t.match(/SRID:([^\s|]+)\|([^|\n]+)\|([^\s\n]+)/);
  if(m){out.id=m[1];out.grade=m[2];out.sectionId=m[3];}
  t.split(/\n+/).forEach(function(line){
    const p=line.split(/[:：]/);
    if(p.length<2)return;
    const k=barcodeNorm(p[0]), v=p.slice(1).join(':').trim();
    if(k.indexOf('اسم')>=0)out.name=v;
    else if(k.indexOf('صف')>=0)out.grade=v;
    else if(k.indexOf('شعب')>=0)out.section=v;
    else if(k.indexOf('تسلسل')>=0)out.seq=v;
    else if(k.indexOf('نتيج')>=0)out.result=v;
    else if(k.indexOf('بطاق')>=0||k.indexOf('وطني')>=0)out.nationalId=toWesternDigits(v);
    else if(v) out.subjects.push({subject:p[0].trim(),value:v});
  });
  if(!out.name&&!out.id) out.name=t.split(/\n/)[0];
  return out;
}
function barcodeFindStudent(parsed){
  const wantName=barcodeNorm(parsed.name);
  const wantGrade=barcodeNorm(parsed.grade);
  const wantSec=barcodeNorm(parsed.section);
  const wantId=parsed.id;
  const wantNat=toWesternDigits(parsed.nationalId||parsed.raw||'');
  let found=null,score=0;
  gradebookGradeLabels().forEach(function(grade){
    gbSectionsForGrade(grade).forEach(function(section){
      (section.students||[]).forEach(function(st){
        let sc=0;
        if(wantId&&st.id===wantId) sc+=100;
        if(wantNat&&st.nationalId&&toWesternDigits(st.nationalId)===wantNat) sc+=80;
        if(wantName&&barcodeNorm(st.name)===wantName) sc+=40;
        else if(wantName&&wantName.length>=4&&(barcodeNorm(st.name).indexOf(wantName)>=0||wantName.indexOf(barcodeNorm(st.name))>=0)) sc+=28;
        if(wantGrade&&barcodeNorm(grade)===wantGrade) sc+=15;
        if(wantSec&&(barcodeNorm(section.label)===wantSec||barcodeNorm(section.id)===wantSec)) sc+=15;
        if(sc>score){score=sc;found={student:st,grade:grade,section:section,score:sc};}
      });
    });
  });
  if(!found||found.score<28)return null;
  return found;
}
function barcodeSubjectRows(grade,sectionId,studentId){
  const subjects=typeof gbSubjects==='function'?gbSubjects(grade):[];
  return subjects.map(function(sub){
    const rec=typeof gbRecord==='function'?gbRecord(grade,sectionId,sub,false):null;
    const row=rec&&rec.rows?rec.rows[studentId]:null;
    let value='';
    if(row){
      if(typeof usesSixthGradeLayout==='function'&&usesSixthGradeLayout(grade)){
        if(typeof gbCompute56==='function')gbCompute56(row);
        value=row.finalGrade;
      }else value=row.finalExam;
    }
    return {subject:sub,value:value};
  });
}

function barcodeDecodeUtf8(s){
  s=String(s||'');
  try{return decodeURIComponent(escape(s));}catch(e){return s;}
}
function barcodeFixText(s){
  s=String(s||'');
  const attempts=[s];
  try{attempts.push(decodeURIComponent(escape(s)));}catch(e){}
  try{
    const bytes=new Uint8Array(s.length);
    for(let i=0;i<s.length;i++) bytes[i]=s.charCodeAt(i)&255;
    attempts.push(new TextDecoder('utf-8').decode(bytes));
  }catch(e){}
  attempts.sort(function(a,b){return ((b.match(/[\u0600-\u06FF]/g)||[]).length)-((a.match(/[\u0600-\u06FF]/g)||[]).length);});
  return attempts[0]||s;
}
function barcodeFromImageData(imgData){
  if(!imgData||!imgData.data||typeof jsQR!=='function')return '';
  try{
    const code=jsQR(imgData.data,imgData.width,imgData.height,{inversionAttempts:'attemptBoth'});
    if(code&&code.data) return barcodeFixText(code.data);
  }catch(e){}
  return '';
}
function barcodeMutate(data, mode, arg){
  const d=new Uint8ClampedArray(data);
  for(let i=0;i<d.length;i+=4){
    let g=d[i]*0.299+d[i+1]*0.587+d[i+2]*0.114;
    if(mode==='contrast'){g=Math.max(0,Math.min(255,(g-128)*arg+128));}
    else if(mode==='thresh'){g=g>=arg?255:0;}
    else if(mode==='invert'){g=255-g;}
    d[i]=d[i+1]=d[i+2]=g;d[i+3]=255;
  }
  return d;
}

  }catch(e){}
  return '';
}

function barcodeTick(){
  if(!BARCODE_SCAN.running)return;
  const video=document.getElementById('barcodeVideo');
  const canvas=document.getElementById('barcodeCanvas');
  if(!video||!canvas){BARCODE_SCAN.raf=requestAnimationFrame(barcodeTick);return;}
  const vw=video.videoWidth||0, vh=video.videoHeight||0;
  if(video.readyState>=2&&vw>0){
    barcodeHideHint();
    const rect=canvas.getBoundingClientRect();
    const dw=Math.max(320,Math.round(rect.width)||640);
    const dh=Math.max(240,Math.round(rect.height)||480);
    if(canvas.width!==dw||canvas.height!==dh){canvas.width=dw;canvas.height=dh;}
    const ctx=canvas.getContext('2d',{willReadFrequently:true});
    ctx.drawImage(video,0,0,dw,dh);
    let text=barcodeFromImageData(ctx.getImageData(0,0,dw,dh));
    if(!text){
      const cx=Math.round(dw*0.12), cy=Math.round(dh*0.16), cw=Math.round(dw*0.76), ch=Math.round(dh*0.68);
      try{text=barcodeFromImageData(ctx.getImageData(cx,cy,cw,ch));}catch(e){}
    }
    if(text){barcodeHandleText(text);return;}
    if(BARCODE_SCAN.detector&&!BARCODE_SCAN.busy){
      BARCODE_SCAN.busy=true;
      const src=canvas;
      BARCODE_SCAN.detector.detect(src).then(function(codes){
        BARCODE_SCAN.busy=false;
        if(codes&&codes[0]&&codes[0].rawValue) barcodeHandleText(barcodeDecodeUtf8(codes[0].rawValue));
      }).catch(function(){BARCODE_SCAN.busy=false;});
    }
  }
  BARCODE_SCAN.raf=requestAnimationFrame(barcodeTick);
}

function barcodeGum(constraints){
  const md=navigator.mediaDevices;
  if(md&&md.getUserMedia) return md.getUserMedia(constraints);
  const legacy=navigator.getUserMedia||navigator.webkitGetUserMedia||navigator.mozGetUserMedia;
  if(!legacy) return Promise.reject(new Error('no-gum'));
  return new Promise(function(resolve,reject){legacy.call(navigator,constraints,resolve,reject);});
}

function barcodeTryDecodeImage(img){
  function runJsQR(sourceImg){
    const widths=[Math.min(1600,sourceImg.width||800),1200,900,700,520,400,320];
    const seen={};
    for(let wi=0;wi<widths.length;wi++){
      const w=Math.max(180,Math.round(widths[wi]));
      if(seen[w])continue;seen[w]=1;
      const h=Math.max(180,Math.round((sourceImg.height||w)*(w/(sourceImg.width||w))));
      const c=document.createElement('canvas');
      c.width=w;c.height=h;
      const ctx=c.getContext('2d');
      ctx.imageSmoothingEnabled=true;
      ctx.drawImage(sourceImg,0,0,w,h);
      const imgData=ctx.getImageData(0,0,w,h);
      let text=barcodeJsQRRaw(imgData.data,w,h);
      if(text)return text;
      const crops=[[0.08,0.08,0.84,0.84],[0.15,0.15,0.7,0.7],[0.2,0.05,0.6,0.55],[0.3,0.3,0.4,0.4]];
      for(let k=0;k<crops.length;k++){
        const cr=crops[k];
        const sx=Math.round(w*cr[0]), sy=Math.round(h*cr[1]), sw=Math.round(w*cr[2]), sh=Math.round(h*cr[3]);
        if(sw<80||sh<80)continue;
        try{
          const part=ctx.getImageData(sx,sy,sw,sh);
          text=barcodeJsQRRaw(part.data,sw,sh);
          if(text)return text;
          const t160=barcodeMutate(part.data,'thresh',160);
          text=barcodeJsQRRaw(t160,sw,sh); if(text)return text;
          const t100=barcodeMutate(part.data,'thresh',100);
          text=barcodeJsQRRaw(t100,sw,sh); if(text)return text;
        }catch(e){}
      }
      const contrast=barcodeMutate(imgData.data,'contrast',1.8);
      text=barcodeJsQRRaw(contrast,w,h); if(text)return text;
      const th=barcodeMutate(imgData.data,'thresh',128);
      text=barcodeJsQRRaw(th,w,h); if(text)return text;
    }
    return '';
  }
  const detPromise=('BarcodeDetector' in window)?(function(){
    try{
      const det=new BarcodeDetector({formats:['qr_code','code_128','code_39','ean_13','codabar','upc_a']});
      return det.detect(img).then(function(codes){
        if(codes&&codes[0]&&codes[0].rawValue) return barcodeFixText(codes[0].rawValue);
        return '';
      }).catch(function(){return '';});
    }catch(e){return Promise.resolve('');}
  })():Promise.resolve('');
  return detPromise.then(function(text){
    if(text)return text;
    return runJsQR(img)||'';
  });
}
function barcodeReadFile(input){
  const file=input&&input.files&&input.files[0];
  if(input) input.value='';
  if(!file)return;
  barcodeSetStatus('تم التقاط الصورة — جاري قراءة الباركود...');
  barcodeShowHint('جاري قراءة الباركود من الصورة...');
  const url=URL.createObjectURL(file);
  const img=new Image();
  img.onload=function(){
    barcodeDrawToViewer(img);
    barcodeTryDecodeImage(img).then(function(text){
      URL.revokeObjectURL(url);
      if(text) barcodeHandleText(text);
      else{
        barcodeSetStatus('الصورة ظهرت في العارض لكن الرمز غير واضح. قرّب الباركود واضغط تشغيل المسح مرة أخرى.');
        barcodeShowHint('قرّب الرمز وأعد التصوير من زر تشغيل المسح');
      }
    }).catch(function(){URL.revokeObjectURL(url);barcodeSetStatus('تعذر تحليل الصورة.');});
  };
  img.onerror=function(){URL.revokeObjectURL(url);barcodeSetStatus('تعذر فتح الصورة.');};
  img.src=url;
}

function authEnsureStaffAccount(emp){
  if(!emp||!emp.id||!authNorm(emp.name))return null;
  if(typeof staffPersonKind==='function'&&staffPersonKind(emp)==='employee')return null;
  authEnsure();
  let acc=AUTH_STATE.accounts.find(function(a){return a.role==='teacher'&&a.staffId===emp.id;});
  if(!acc) acc=AUTH_STATE.accounts.find(function(a){return a.role==='teacher'&&authNorm(a.name)===authNorm(emp.name);});
  if(!acc){
    acc={id:authUid(),role:'teacher',name:authNorm(emp.name),login:authGenLogin('tch'),password:authGenPass(),staffId:emp.id,assignments:[]};
    AUTH_STATE.accounts.push(acc);saveAuthState();
  }else{
    let dirty=false;
    if(acc.staffId!==emp.id){acc.staffId=emp.id;dirty=true;}
    if(authNorm(emp.name)&&acc.name!==authNorm(emp.name)){acc.name=authNorm(emp.name);dirty=true;}
    if(authEnsureLogin(acc,'tch')) dirty=true;
    if(authEnsureUniquePass(acc)) dirty=true;
    if(dirty) saveAuthState();
  }
  return acc;
}

function authAddAssign(){
  const tid=(document.getElementById('asgTeacher')||{}).value||'';
  const t=AUTH_STATE.accounts.find(function(a){return a.id===tid;});
  if(!t){alert('اختر معلماً. أنشئ حسابه من حسابات الدخول أولاً.');return;}
  const grade=(document.getElementById('asgGrade')||{}).value||'';
  const sectionId=(document.getElementById('asgSection')||{}).value||'';
  const subject=(document.getElementById('asgSubject')||{}).value||'';
  const wantSheets=!!(document.getElementById('asgSheets')||{}).checked;
  const wantCare=!!(document.getElementById('asgCare')||{}).checked;
  const wantParents=!!(document.getElementById('asgParents')||{}).checked;
  const wantTime=!!(document.getElementById('asgTime')||{}).checked;
  const wantRec=!!(document.getElementById('asgRec')||{}).checked;
  if(wantCare) t.canCare=true;
  if(wantParents) t.canParents=true;
  if(wantTime) t.canTimetable=true;
  if(wantRec) t.canRecords=true;
  const wantStaffEdit=!!(document.getElementById('asgStaffEdit')||{}).checked;
  if(wantStaffEdit) t.canStaffEdit=true;
  const sheetScope=((document.getElementById('asgSheetScope')||{}).value)||'section';
  if((wantCare||wantParents||wantTime||wantRec||wantStaffEdit) && !grade && !sectionId && !subject && !wantSheets){
    saveAuthState();renderAuthAssign();
    alert('تم تكليف «'+t.name+'» بالمهام العامة المحددة.');
    return;
  }
  if(wantSheets && sheetScope==='stage'){
    if(!t.assignments)t.assignments=[];
    t.assignments.push({
      id:authUid(),grade:grade||'',sectionId:'',sectionLabel:'كل المرحلة',subject:subject||'كشوف النتائج',
      grades:false,levels:false,attendance:false,questions:false,examlist:false,homework:false,
      records:wantRec,sheets:true,care:wantCare,sheetScope:'stage',stage:typeof currentStage==='function'?currentStage():''
    });
    saveAuthState();renderAuthAssign();return;
  }
  if(!grade){alert('اختر الصف.');return;}
  if(wantSheets && sheetScope==='grade'){
    if(!t.assignments)t.assignments=[];
    t.assignments.push({
      id:authUid(),grade:grade,sectionId:'',sectionLabel:'كل الشعب',subject:subject||'كشوف النتائج',
      grades:false,levels:false,attendance:false,questions:false,examlist:false,homework:false,
      records:wantRec,sheets:true,care:wantCare,sheetScope:'grade'
    });
    saveAuthState();renderAuthAssign();return;
  }
  if(!sectionId){alert('اختر الشعبة.');return;}
  if(!subject && !wantSheets && !wantCare){alert('اختر المادة أو مهمة كشوف النتائج.');return;}
  const sec=gbSectionById(grade,sectionId);
  if(!t.assignments)t.assignments=[];
  t.assignments.push({
    id:authUid(),grade:grade,sectionId:sectionId,sectionLabel:sec?sec.label:'',subject:subject||'مرشد الصف',sheetScope:wantSheets?'section':'',
    grades:!!(document.getElementById('asgGrades')||{}).checked && !!subject,
    levels:!!(document.getElementById('asgLevels')||{}).checked && !!subject,
    attendance:!!(document.getElementById('asgAtt')||{}).checked,
    questions:!!(document.getElementById('asgQ')||{}).checked,
    examlist:!!(document.getElementById('asgExam')||{}).checked,
    homework:!!(document.getElementById('asgHw')||{}).checked,
    records:wantRec,
    sheets:wantSheets,
    care:wantCare,parents:wantParents,timetable:wantTime
  });
  saveAuthState();renderAuthAssign();
}

function studentCtx(){
  const me=authMe();if(!me)return null;
  let grade=me.grade, sectionId=me.sectionId, studentId=me.studentId, studentName=me.name, found=null;
  function matchSt(st){
    if(!st)return false;
    if(studentId&&st.id===studentId)return true;
    if(me.studentId&&st.id===me.studentId)return true;
    if(authNorm(st.name)&&authNorm(st.name)===authNorm(me.name))return true;
    return false;
  }
  gradebookGradeLabels().some(function(g){
    return gbSectionsForGrade(g).some(function(sec){
      const st=(sec.students||[]).find(matchSt);
      if(st){found=st;grade=g;sectionId=sec.id;studentId=st.id;studentName=st.name;return true;}
      return false;
    });
  });
  if(!found&&studentId){
    gradebookGradeLabels().some(function(g){
      return gbSectionsForGrade(g).some(function(sec){
        const st=(sec.students||[]).find(function(s){return s.id===studentId;});
        if(st){found=st;grade=g;sectionId=sec.id;studentName=st.name;return true;}
        return false;
      });
    });
  }
  let sectionLabel='';
  if(grade&&sectionId){const secs=typeof gbSectionsForGrade==='function'?gbSectionsForGrade(grade):[]; const sec=(secs||[]).find(function(s){return s.id===sectionId;}); if(sec) sectionLabel=sec.label||'';}
  return {me:me,grade:grade,sectionId:sectionId,sectionLabel:sectionLabel,studentId:studentId,studentName:studentName};
}

function mailPickFile(kind){
  const inp=document.createElement('input');
  inp.type='file';
  inp.accept=kind==='img'?'image/*':(kind==='xls'?'.xlsx,.xls,.csv,application/vnd.ms-excel,application/vnd.openxmlformats-officedocument.spreadsheetml.sheet':'application/pdf,.pdf');
  inp.onchange=function(){
    const f=inp.files&&inp.files[0]; if(!f)return;
    if(kind==='img'){
      const img=new Image();
      const fr=new FileReader();
      fr.onload=function(){
        img.onload=function(){
          const c=document.createElement('canvas');
          let w=img.width,h=img.height,max=1000;
          if(w>max){h=h*max/w;w=max;}
          if(h>max){w=w*max/h;h=max;}
          c.width=w;c.height=h;
          c.getContext('2d').drawImage(img,0,0,w,h);
          const data=c.toDataURL('image/jpeg',0.72);
          mailAttachSet(data,'image',f.name||'صورة.jpg');
        };
        img.src=fr.result;
      };
      fr.readAsDataURL(f);
      return;
    }
    if(kind==='xls'){
      if(f.size>900000){alert('ملف إكسل كبير. اختر ملفاً أصغر من 900 ك.ب.');return;}
      const fr=new FileReader();
      fr.onload=function(){ mailAttachSet(fr.result,'excel',f.name||'جدول.xlsx'); };
      fr.readAsDataURL(f);
      return;
    }
    if(f.size>700000){alert('ملف PDF كبير. اختر ملفاً أصغر من 700 ك.ب.');return;}
    const fr=new FileReader();
    fr.onload=function(){ mailAttachSet(fr.result,'pdf',f.name||'ملف.pdf'); };
    fr.readAsDataURL(f);
  };
  inp.click();
}

async function cloudPushNow(){

  if(CLOUD_BUSY)return false;
  CLOUD_BUSY=true;
  cloudSetStatus('جاري الرفع…');
  try{
    const res=await fetch(cloudEndpoint(),{method:'PUT',headers:{'Content-Type':'application/json'},body:JSON.stringify(cloudPack())});
    if(!res.ok) throw new Error('HTTP '+res.status);
    CLOUD_LAST=Date.now();
    cloudSetStatus('تم الرفع إلى السحابة',true);
    return true;
  }catch(e){
    cloudSetStatus('فشل الرفع: تحقق من الرابط وقواعد Firebase',false);
    return false;
  }finally{CLOUD_BUSY=false;}
}

    const res=await fetch(cloudEndpoint(), ac?{signal:ac.signal}:{});
    if(to)clearTimeout(to);

    cloudApplyFull(pack);
    cloudSetStatus('تم تحديث البيانات من السحابة',true);

    return true;
  }catch(e){
    if(!silent)cloudSetStatus('فشل السحب — تحقق من الإنترنت والرابط',false);

  }
}

function publicSlugName(name){
  var t=String(name||'').trim().toLowerCase();
  var map={'أ':'a','ا':'a','إ':'a','آ':'a','ب':'b','ت':'t','ث':'th','ج':'j','ح':'h','خ':'kh','د':'d','ذ':'th','ر':'r','ز':'z','س':'s','ش':'sh','ص':'s','ض':'d','ط':'t','ظ':'z','ع':'a','غ':'gh','ف':'f','ق':'q','ك':'k','ل':'l','م':'m','ن':'n','ه':'h','و':'w','ي':'y','ى':'a','ة':'a','ء':'','ؤ':'w','ئ':'y'};
  var out='';
  for(var i=0;i<t.length;i++){
    var ch=t.charAt(i);
    if(map[ch]) out+=map[ch];
    else if(/[a-z0-9]/.test(ch)) out+=ch;
    else if(/\s|-|_/.test(ch)) out+='-';
  }
  out=out.replace(/-+/g,'-').replace(/^-|-$/g,'');
  if(!out) out='sch'+String(Date.now()).slice(-6);
  if(out.length>18) out=out.slice(0,18);
  return out;
}

      // emit the initial null value and falsely stop a brand-new account before its first
      // registration record is written.
      fbRef("activation/accounts/"+emailKey).once("value",function(snap){
        const remote=snap.val();
        if(remote && (remote.accountDisabled||["approved","suspended","disabled","deleted","cancelled","pending","device_transfer_pending","rejected","device_conflict"].includes(remote.status))){
          applyCloudAccount(acc,remote);
          if(done)done(true);
          return;
        }
        fbRef("activation/accounts/"+emailKey).update(payload,function(err){
          if(done)done(!err);
        });
      },function(){ if(done)done(false); });
    }catch(e){if(done)done(false);}
  }

  function markAccountStopped(acc,reason,cb){
    if(acc){
      acc.status="suspended";
      acc.accountDisabled=true;
      acc.disabledReason=reason||"تم إيقاف الحساب من الإدارة";
      saveState(state);
    }
    cb&&cb({stopped:true,reason:reason||"تم إيقاف الحساب من الإدارة"});
  }
  function applyCloudAccount(acc,v,cb){
    if(!acc)return;
    // An empty read is only treated as "removed by admin" once we've already confirmed a
    // real record existed in the cloud at least one time before. Admin suspension/deletion
    // always writes an explicit accountDisabled/status flag first (see admin.html), so a
    // missing record never represents a genuine stop on its own — it only ever means the
    // very first sync of a brand-new account (or a slow/offline connection) hasn't reached
    // the server yet. Treating that as "deleted" was locking out brand-new customers.
    if(!v){
      if(acc.cloudConfirmed){ markAccountStopped(acc,"تم حذف أو إيقاف حسابك من الإدارة",cb); return; }
      cb&&cb({pending:true}); return;
    }
    acc.cloudConfirmed=true;
    if(v.accountDisabled||["suspended","disabled","deleted","cancelled"].includes(v.status)){
      markAccountStopped(acc,v.disabledReason||"تم إيقاف الحساب من الإدارة",cb);return;
    }
    if(v.schoolName)acc.schoolName=v.schoolName;
    if(v.phone)acc.phone=v.phone;
    if(v.status==="approved" && !v.activeDeviceId && state.activeEmail===acc.email){
      /* الاشتراك محرَّر (خرج صاحبه من جهازه): هذا الجهاز يحجزه — وإن سبقه جهاز آخر يُعاد الفحص فوراً */
      claimDevice(acc.email,function(ok){ if(!ok) setTimeout(function(){ try{ cloudValidateNow(); }catch(e){} },300); });
    }
    if(v.status==="approved" && (!v.activeDeviceId || v.activeDeviceId === deviceId())){
      acc.status="approved";
      acc.plan=normalizePlan(v.plan||v.planCode||acc.plan);
      acc.expiresAt=v.expiresAt||acc.expiresAt;
      acc.activatedAt=v.activatedAt||acc.activatedAt;
      acc.paidAmount=v.paidAmount||acc.paidAmount;
      acc.activeDeviceId=deviceId();
      acc.accountDisabled=false;
      saveState(state); cb&&cb({activated:true}); return;
    }
    if(v.status==="approved" && v.activeDeviceId && v.activeDeviceId !== deviceId()){
      acc.status="device_conflict";
      saveState(state); cb&&cb({conflict:true}); return;
    }
    if(v.status==="device_transfer_pending"){
      if(v.activeDeviceId === deviceId()){
        acc.status="device_transfer_pending"; saveState(state);
        cb&&cb({transferPending:true}); return;
      }
      acc.status="approved";
      acc.plan=normalizePlan(v.plan||v.planCode||acc.plan);
      acc.expiresAt=v.expiresAt||acc.expiresAt;
      saveState(state); cb&&cb({activated:true}); return;
    }
    if(v.status==="rejected"){
      if(v.activeDeviceId === deviceId()){
        acc.status=acc.phone?"pending":"trial";
        saveState(state); cb&&cb({rejected:true}); return;
      }
      acc.status="approved";
      acc.plan=normalizePlan(v.plan||v.planCode||acc.plan);
      acc.expiresAt=v.expiresAt||acc.expiresAt;
      saveState(state); cb&&cb({activated:true}); return;
    }
    if(v.status==="pending"){
      acc.status="pending"; saveState(state); cb&&cb({pending:true}); return;
    }
    if(v.status==="trial"||!v.status){
      acc.status="trial";
      acc.expiresAt=v.expiresAt||acc.expiresAt;
      saveState(state); cb&&cb({trial:true}); return;
    }
  }
  function cloudValidateNow(done){
    if(!navigator.onLine){if(done)done(false);return;}
    const acc=currentAccount();
    if(!acc||!initFB()||!fbReady){if(done)done(false);return;}
    lastCheck=now();
    try{
      fbRef("activation/accounts/"+acc.email.replace(/\./g,",")).once("value",function(snap){
        applyCloudAccount(acc,snap.val(),function(ev){
          if(ev&&ev.stopped){showOverlay();screenAccountStopped(ev.reason);}
          else if(ev&&ev.conflict){showOverlay();screenConflict();}
          else if(ev&&ev.activated){refreshActivateButton();}
        });
        if(done)done(true);
      },function(){
        // Network failure: keep the local account usable offline.
        if(done)done(false);
      });
    }catch(e){if(done)done(false);}
  }
  function listenAccount(acc, cb){
    if(!fbReady||!acc) return;
    if(cb) liveCb=cb;
    if(state.activeEmail===acc.email && isSettled()){ stopLive(); return; }   /* مفعّل: بلا اتصال دائم */
    if(liveRef && liveRef.__email===acc.email) return;                        /* مستمع واحد فقط */
    stopLive();
    const emailKey = acc.email.replace(/\./g,",");
    const r=fbRef("activation/accounts/"+emailKey); r.__email=acc.email; liveRef=r;
    r.on("value", function(snap){
      applyCloudAccount(acc,snap.val(),function(ev){
        liveCb&&liveCb(ev);
        if(ev&&ev.stopped){showOverlay();screenAccountStopped(ev.reason);}
        if(state.activeEmail===acc.email && isSettled()) setTimeout(stopLive,1500);
      });
    });
  }
  /* الحساب المفعّل: فحص كل ساعة، وعند الرجوع للبرنامج بعد غياب ربع ساعة */
  setInterval(function(){ try{ if(isSettled() && navigator.onLine) cloudValidateNow(); }catch(e){} },3600000);
  document.addEventListener("visibilitychange",function(){ try{ if(document.visibilityState==="visible" && isSettled() && navigator.onLine && now()-lastCheck>900000) cloudValidateNow(); }catch(e){} });

    else if(digits.startsWith("964")) digits=digits.slice(3);
    if(digits.length===10&&!digits.startsWith("0")) digits="0"+digits;
    return digits;
  }
